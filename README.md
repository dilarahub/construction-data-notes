# Construction Data Notes

## Overview

A structured technical knowledge base for project controls, schedule integrity, Earned Value Management (EVM), Primavera P6 practices, and Power BI/DAX concepts used in construction and industrial project reporting.

**Project status:** Knowledge-base structure established. Technical articles and examples will be added incrementally and reviewed before publication.

## Editorial Principles

- Distinguish recognised industry methodologies from personal implementation notes.
- Cite authoritative, publicly available references where appropriate.
- Document assumptions and limitations clearly.
- Use concise, reproducible, synthetic examples when demonstrations are added.
